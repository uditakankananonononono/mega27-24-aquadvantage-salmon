# Salmon RNA-seq payload inventory and read-count reconciliation

The [2022 article Table 1](https://pmc.ncbi.nlm.nih.gov/articles/PMC9168996/) lists 18 libraries. The current [ENA PRJNA766994 run report](https://www.ebi.ac.uk/ena/portal/api/filereport?accession=PRJNA766994&result=read_run&fields=run_accession%2Csample_accession%2Cread_count%2Cbase_count%2Cfastq_bytes%2Clibrary_layout&format=tsv) exposes 18 distinct runs and samples, each with two paired FASTQ files. For **all 18/18** run accessions, Table 1's “Raw reads #” is exactly **twice** ENA's `read_count`: 1,840,665,156 article individual mate reads versus 920,332,578 ENA fragments. ENA reports 184,066,515,600 sequenced bases, and the sum of advertised compressed FASTQ byte sizes is 116,626,831,384 (about 116.6 GB decimal). The replay script and test pin original article XML and fresh ENA metadata TSV hashes and join all 18 rows without row-order assumptions.

This is a useful provenance check: unlike an apparent 2x mismatch, the table and archive agree on paired-end counting units. It is still metadata, not sequence or per-sample expression analysis. The 116.6 GB payload was not downloaded, so 18 accession records are **not** fetched-and-used accession datasets for the locked gate. Author spreadsheets summarize selected comparisons but do not provide an all-transcript per-sample count matrix. An independent same-task cohort and fair comparator remain absent; no biological or product-level claim follows from the inventory.
