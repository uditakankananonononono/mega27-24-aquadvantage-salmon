# Salmon supplementary RefSeq label cardinality, 2026-09-28

The [2022 transcript article](https://pmc.ncbi.nlm.nih.gov/articles/PMC9168996/) has three [published processed comparison tables](https://www.ebi.ac.uk/europepmc/webservices/rest/PMC9168996/supplementaryFiles) S1-S3. A metadata-only scan finds 4,678, 1,010 and 538 transcript rows; the printed `RefSeq mRNA Assession` column is blank on 1,116, 236 and 108 rows, respectively. Among nonblank strings, 3,436 distinct exact labels appear, and 614 exact labels are associated with more than one distinct TCONS transcript ID across these tables, at most 12 in one label. The same transcript can appear in multiple pairwise tables; the script deduplicates transcript IDs per label. Labels with and without version suffixes are kept distinct exact strings. This is an annotation cardinality warning: neither rows nor RefSeq labels are independent data accessions or biological replicates. No RefSeq records were individually fetched, and no sequence or expression analysis is inferred. No gate credit.
