# Same-cohort three-temperature comparison consistency

The [2022 salmon article](https://pmc.ncbi.nlm.nih.gov/articles/PMC9168996/) supplies author-selected DET summaries in [original supplementary spreadsheets S1–S3](https://www.ebi.ac.uk/europepmc/webservices/rest/PMC9168996/supplementaryFiles). The green highlighted rows are the authors' concordant classifications, not our own expression calls. Cross-joining exact transcript IDs in all three pairwise comparisons finds **16 transcripts green in all three**. The pairwise overlaps are 164 (S1/S2), 50 (S1/S3) and 17 (S2/S3); these overlap sets are not independent validation cohorts. For all 16 triple-overlap IDs, the published mean FPKM for each shared temperature matches between its two relevant spreadsheets. Simple positive FPKM ratios are algebraically transitive across 10.5, 13.5 and 16.5 C for 16/16. The script records original spreadsheet hashes, all IDs/means and a replay test.

This is a useful input-integrity check before any source-level analysis. It is **not** evidence that author edgeR/DESeq2 model fold changes multiply exactly, nor a reproduced differential-expression result, independent cohort, product-level claim or new discovery. The raw per-sample transcript matrix is still absent from these spreadsheets. No project gate credit is assigned.
