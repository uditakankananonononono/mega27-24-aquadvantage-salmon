# Fillet and liver results share fish, 2026-09-28

The [2022 AquAdvantage salmon RNA-seq article](https://pmc.ncbi.nlm.nih.gov/articles/PMC9168996/) explicitly states that fillet samples were collected from the same fish sampled for liver transcript expression. Its Figure 8 correlation diagram and PCA use those same fish's measured composition, morphometrics and selected transcript readouts. Thus the published cross-tissue association is a within-cohort observation, not a separate fillet-cohort external validation of a new liver-based predictor. The earlier thesis-to-paper source link reinforces this dependence, but the source text does not supply individual fish records for our reanalysis. This script checks only the article's provenance passages; it does not digitize Figure 8, infer performance, or claim biological novelty. No project gate credit.
