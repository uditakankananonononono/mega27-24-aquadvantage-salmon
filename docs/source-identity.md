# AquAdvantage-adjacent source-identity screen, 2026-09-26

The [original 2022 Frontiers Genetics paper](https://pmc.ncbi.nlm.nih.gov/articles/PMC9168996/) describes female triploid growth-hormone transgenic Atlantic salmon at three temperatures (10.5, 13.5 and 16.5 degrees C), six hepatic RNA-seq replicate libraries per temperature. Its Table 1 names 18 SRR runs. The live [ENA PRJNA766994 report](https://www.ebi.ac.uk/ena/portal/api/filereport?accession=PRJNA766994&result=read_run&fields=run_accession%2Cexperiment_accession%2Csample_accession%2Cstudy_accession&format=tsv) lists exactly those 18 runs, one linked study. The original article XML, article run list and ENA report are archived with SHA-256 in `results/source_identity.json`; `scripts/check_source_identity.py` verifies the accession join and one test replays it.

This is **metadata/source identity**, not reads ingested, transcriptomic replication, growth-curve analysis, environmental safety assessment or an independently validated discovery. It is an article about a specific research cohort, not license to assume product-level or field-level equivalence for AquAdvantage salmon. One study and 18 run metadata rows must not be called 18 independent datasets in the gate tally. No construct/organism/sequence design work is in scope. Before analysis: check the original paper's processed data availability, experimental covariates and independent cohort; prespecify a baseline and held-out comparison. All project gates remain unverified/open; no success inferred from this screen.
